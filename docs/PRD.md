# PRD — DS-Helper (사용자 웹)

## 한 줄 요약

**대구 달성군** 주민을 위한 생활밀착형 플랫폼으로, 생활 돌봄·동행 **도움 예약**, **커뮤니티**, **공공 쓰레기통 지도**, **고객 문의**를 하나의 웹 앱에서 제공한다.

## 문제·배경

- 지역 주민(어르신, 1인 가구, 맞벌이 부모 등)이 일상 도움·정보를 찾기 어렵다.
- 달성군 내 복지·생활 지원을 디지털 채널로 연결할 필요가 있다.
- 쓰레기통 위치 등 생활 인프라 정보를 지도로 제공해 주민 편의를 높인다.

## 사용자

| 유형 | 설명 | 로그인 |
|------|------|--------|
| 개인 회원 | 도움 요청·게시판·문의 | 카카오 / 구글 / 네이버 |
| 기관 회원 | 기관 명의 도움 예약 | ID·PW (`/login/org`) |
| 비회원 | 홈·일부 콘텐츠 열람 | — |

## 핵심 기능 (In Scope)

### 1. 도움 요청·예약

- 로그인 후 도움 유형·일시·요구사항 입력 (`/help`, `/help/modify`)
- 개인/기관 API 분기 (`personal-reservations` / `organization-reservations`)
- 예약 목록·상세·취소 (`/helpList`)
- 완료 안내 (`/help/complete`)

### 2. 도와드린 이야기

- 사례·후기형 콘텐츠 목록·상세 (`/helpStory`)
- 홈에서 최신 글 노출

### 3. 커뮤니티 게시판

- 목록·작성·상세·수정·삭제
- 좋아요·스크랩·댓글·대댓글

### 4. 공공 쓰레기통 지도

- 달성군 내 쓰레기통 위치 지도 표시 (`/trash-bin-list`)
- 모바일 우선 UI, 위치 1회 조회 후 목록 로드
- 마커 선택 → 상세·카카오맵 길찾기(출발/도착)·공유

### 5. 고객 문의

- 문의 유형·내용·이미지 등록
- 내 문의 목록·답변 보기 (`/customer`)

### 6. 계정

- 프로필·이름 수정·스크랩·내 글·탈퇴 (`/account/*`)
- SNS 연동 해제 API

### 7. 알림 (UI)

- 헤더 알림 모달 UI 존재
- **백엔드 연동은 미완** (로드맵 참고)

## 비목표 (Out of Scope — 이 저장소)

- 어드민 콘솔 (`admin.dshelper.kr` — 별도 앱)
- 백엔드 비즈니스 규칙·정산·매칭 알고리즘 상세
- 네이티브 앱 (웹 반응형·모바일 브라우저 대상)

## 성공 지표 (제안)

- 예약 생성·완료 전환율
- 게시판·지도 MAU (달성군 거주·이용 검증은 운영 정책과 연계)
- 문의 응답 SLA (운영)

## 제약·의존성

- 백엔드 API 가용성 ([backend](https://github.com/DS-Helper/backend))
- 카카오 지도·OAuth 키 및 Redirect URI 정합
- 배포: 프로덕션 EC2, 테스트 Netlify ([DEPLOY.md](./DEPLOY.md))
