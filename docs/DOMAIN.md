# 도메인·지역 맥락

## 공식 서비스 지역

**대구광역시 달성군** (대구 달성군)

- 홈·메타: 「디에스헬퍼 - 달성군 생활밀착형 플랫폼」
- 휴지통·생활 인프라 데이터는 달성군 운영 데이터·백엔드 제공 범위에 따름

## 서비스 명칭

| 표기 | 사용처 |
|------|--------|
| DS-Helper / 디에스헬퍼 / DS Helper | 브랜드·UI 카피 혼용 |
| dshelper.kr | 프로덕션 도메인 |

문서·UI 신규 작성 시 **「디에스헬퍼」** 또는 **「DS-Helper」** 중 하나로 팀 내 통일을 권장합니다.

## 사용자·역할 용어

| 용어 | 의미 |
|------|------|
| 개인 회원 | SNS 로그인 주민 (`userType: individual`) |
| 기관 회원 | 복지관·마을회관 등 (`userType: organization`) |
| 도움 요청 | 생활 돌봄·동행 등 예약 단위 |
| 도와드린 이야기 | 서비스 사례·후기 콘텐츠 (`/helpStory`) |

## 도움 유형 (홈 기준 카피)

- 생활 돌봄 지원 (장보기, 병원 동행, 집안 정리 등)
- 정서적 돌봄 (말벗, 산책 동행)
- 아이 돌봄 지원
- 청년·성인 대상 지원
- 기관·단체 대상 지원

실제 예약 폼 옵션은 `help/modify` 및 백엔드 스키마를 따릅니다.

## 지역 플랫폼으로서의 문서 원칙

1. **포트폴리오형 일반 설명 지양** — 달성군·실제 이용 시나리오를 적는다.
2. **백엔드와 경계 명시** — 데이터 출처·검증은 백엔드/운영 문서.
3. **테스트 URL 구분** — 주민 대면은 `dshelper.kr`, QA는 `test.dshelper.kr`.
4. **어드민과 분리** — 운영자 기능은 `admin.dshelper.kr` (이 레포 문서 범위 밖).
